
\section{Data Analysis Using Machine Learning}\label{sec:ML}
The classification of signal and background events in this analysis employs machine learning techniques following the framework presented in Sec.~\ref{sec:machine_learning}. As established in that section, machine learning classifiers can simultaneously process multiple kinematic variables and capture complex correlations within high-dimensional feature spaces, providing superior discrimination compared to sequential cut-based selections. Among the various algorithms discussed in Sec.~\ref{sec:machine_learning}—including logistic regression, Random Forests, and DNN's and BDT's offer a particularly favorable balance for collider physics applications.

As detailed in Sec.~\ref{ssec:xgboost}, BDTs construct ensembles through sequential training, where each tree corrects the residual errors of its predecessors. This iterative refinement process, combined with gradient-based optimization and regularization techniques implemented in XGBoost, enables BDTs to achieve high classification accuracy while maintaining computational efficiency and model interpretability. The standard ML workflow outlined in Sec.~\ref{ssec:ml_workflow}—encompassing data preparation, feature preprocessing, hyperparameter optimization via cross-validation, and output score generation—forms the foundation for the analysis strategy applied here. This section describes the specific implementation of this framework for the present study. 

Our analysis begins with a custom \texttt{MadAnalysis Expert Mode} script~\parencite{CONTE2013222}, which retrieves key kinematic and topological data from the simulated event samples. This script processes the relevant variables and converts them into a well-organized CSV (Comma-Separated Values) file format suitable for training machine learning models. The extracted kinematic information encompasses critical event characteristics, including particle momenta, energies, and topological features, which serve as the foundational input for the machine learning framework. 

Cross-section weighting is implemented to properly account for the differing statistical significance of events, as detailed in Sec.~\ref{sec:power_analysis}. This procedure ensures proper balance between the relative contributions of signal and background events within the dataset, which is essential given the variable probabilities of observing different event types in high-energy physics collisions. Following weighting, the datasets undergo initial filtering through our \texttt{MadAnalysis Expert Mode} C++ script before being exported to CSV format for machine learning processing. The filter requirements mandate at least one properly reconstructed and tagged $\mathrm{b}$-jet candidate, a minimum of one additional jet (standard or FJ) without $\mathrm{b}$-tagging, and precisely three identified muons. These selection criteria are guided by experimental realities, including detector geometries of CMS/ATLAS, standard kinematic reconstruction thresholds, and lepton trigger specifications that establish minimum kinematic requirements. Consistent with the kinematic phase space in the Madgraph Simulations, jets are required to satisfy $p_{\mathrm{T}} > 30$ $\textrm{GeV}$ and $|\eta(j)| < 5.0$, while $\mathrm{b}$-jet candidates must meet $p_{\mathrm{T}} > 20$ $\textrm{GeV}$ and $|\eta(\mathrm{b})| < 2.5$. Muons must satisfy $p_{\mathrm{T}} > 35$ $\textrm{GeV}$ and $|\eta(\ell)| < 2.3$. These selection requirements are henceforth termed pre-selections. Pre-selection efficiency varies with $m(\phi')$ and $m(\chi_{\mathrm{u}})$, but typically ranges from $25-30$\% for signal events. Events surviving pre-selection serve as input to the machine learning classifier, which assigns each event a probability-based signal or background classification. 



Our investigation examines multiple machine learning architectures, comprising three distinct neural network configurations and a BDT classifier. For rigorous model validation, we implement a conventional 90-10 training-testing data partition, allocating 90\% of events for model training and reserving 10\% for evaluation. This partitioning strategy enables assessment of model generalization performance on previously unseen data.  

Model training and testing were conducted using high-performance computational resources, specifically utilizing an Nvidia A100 GPU. Neural network development, training, and evaluation were performed using the \texttt{PyTorch}~\parencite{paszke2019} deep learning library, which is widely recognized for its versatility and efficiency in deep learning tasks.

Three distinct fully-connected (FC) neural network configurations were tested: Neural Network 1 (NN1) employs 3 FC layers with node counts of 32, 64, and 1; Neural Network 2 (NN2) features 4 FC layers with 64, 128, 128, and 1 nodes; and Neural Network 3 (NN3) incorporates a more elaborate structure with 5 FC layers containing 64, 128, 512, 128, and 1 nodes. These progressively complex architectures enable evaluation of the relationship between network depth and classification capability.

The BDT classifier is configured with hyperparameters $\eta=0.3$, $\gamma = 0$, and $\texttt{max\_depth} = 6$. Implementation of the Boosted Decision Tree is achieved through the \texttt{XGBoost}~\parencite{chen_xgboost_2016} library, selected for its computational efficiency, optimization capabilities, and model interpretability, qualities that make it well-matched to this analysis.

Tab.~\ref{tab:ml_results} summarizes the training and evaluation results for all tested models. All classifiers demonstrate outstanding performance, with testing accuracies above 99.9\%. The BDT attains 99.93\% testing accuracy, while the neural network architectures show slightly superior accuracies between 99.97\% and 99.98\%. Nevertheless, this marginal performance gain entails substantial computational expense: neural networks demand training durations of 1 hour 58 minutes to 2 hours 32 minutes, whereas the BDT trains in only 6 seconds—a computational speedup exceeding three orders of magnitude.

We note that various deep neural network architectures were tested during our investigations. While these networks produce signal sensitivity comparable to the BDT, the intricate nature of this analysis—including the particle object considerations, experimental constraints at high-luminosity LHC conditions, and other factors—favors adoption of the BDT. This preference stems from the BDT's practical utility, computational efficiency, interpretability of results, and dramatically reduced training duration. Consequently, the BDT serves as the classifier for all subsequent analyses presented in this work
